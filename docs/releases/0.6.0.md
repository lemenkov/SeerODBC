SeerODBC 0.6.0 is a **feature-parity release**: what worked only on newer servers now works on Oracle 8i, 9i, 10g and 11g too. That covers PL/SQL LOB parameters, national-character parameters on 8i, REF binds on 10g / 11g, and parameter arrays every tier runs correctly. It also makes **real TCPS listeners** connect, and moves the whole wire layer onto declarative schemas, checked against a recorded replay of every tier.

### Changes you may notice

None of these needs a code change, but an application could see a difference:

- **A query with a parameter array is refused, on every tier** (#430, #417). A SELECT run with `SQL_ATTR_PARAMSET_SIZE` > 1 used to answer only one parameter set's rows: the first on 10g and later, the last on 9i. It still reported every set as processed. Such a query is now HYC00, "a query can't run with an array of parameter sets: run it once per set", before anything is sent. `SQL_PARAM_ARRAY_SELECTS` has always said `SQL_PAS_NO_SELECT`. One result set per parameter set is a possible later feature (#431).
- **An array execute of a PL/SQL block runs every parameter set** (#428). Every tier ran it once, with the first set, and reported success.
- **An expired login timeout is HYT00**, not 08001 "I/O error" (#403). Over TLS, a server that stopped answering never timed out at all.
- **Proxy authentication (`user[schema]`) below 10g is refused** with HYC00, "proxy authentication (user[schema]) needs Oracle 10g or later" (#411). On 8i the login succeeded but the session ran as the proxy user, not the client, so an application acted as the wrong user without knowing it.
- **On 11g, an XMLType value stored as binary XML** (11g's default storage) is that cell's error, naming the workaround (#416). It read as NULL with no error. Select `XMLSERIALIZE(DOCUMENT col AS CLOB)` or `col.getClobVal()` to read it.
- **SQLDisconnect refuses with 25000 on 9i** while a manual-mode transaction is open, as it already did on every other tier (#344). 9.2 committed the pending work at logoff.

### New features

- **Oracle 8i:**
  - **National-character parameters** (#419). `seer_stmt_bind_ntext` binds in NCHAR form. ODBC sends 8i parameters in CHAR form, and when 8.1.7 answers ORA-12704 (character-set mismatch), the execute runs once more with the `SQL_WCHAR` / `SQL_WVARCHAR` / `SQL_WLONGVARCHAR` parameters in NCHAR form. An `NVARCHAR2` column can now be written through ODBC on 8i.
  - **Text and RAW values for PL/SQL CLOB / BLOB parameters**, at any length (#424). 8.1.7 converts neither, so the driver passes them as temporary LOBs, made and filled by the server and freed after the execute. When a block answers PLS-00306, ODBC runs it once more with its `SQL_LONGVARCHAR` / `SQL_WLONGVARCHAR` / `SQL_LONGVARBINARY` parameters as LOBs.
- **10g and 11g:**
  - **CLOB / BLOB parameters over 32 KB to PL/SQL** (#415). These go as temporary LOBs, as on 12c and later.
  - **REF binds**, IN and OUT, in JDBC thin's form (#241). `SQL_SEER_REF` parameters now work on every tier.
- **9i:** **SQLDisconnect knows whether a transaction is open** (#344), through `DBMS_TRANSACTION`, queried only in manual-commit mode.
- **Parameter arrays that only a single-row path can run** now run a row at a time inside the driver (#418, #428). They report what one array execute would: summed row counts, the last row's OUT values, and per-row batch errors. These are a PL/SQL block on any tier, and on 8i / 9i an array DML with RETURNING, text over 4000 bytes, or a value over 32 KB.
- **Core API:**
  - **`seer_stmt_bind_clob` / `seer_stmt_bind_blob`** bind text / bytes for a CLOB / BLOB target, on every tier (#424).
  - **`seer_txn_check`** answers whether a transaction is open, on every tier (#344).
  - **`SEER_ETIMEOUT`** is the status for an expired connect or login time limit (#403).
- **seersql:** a failed connect prints the server's or the listener's reason, such as `ORA-12514` or `ORA-01017`, not a bare "protocol error" (#401).

### Fixes

- **Every connect to a real Oracle TCPS listener failed** with 08001 (#405). The listener asks for a new TLS handshake on the same connection, through its RESEND, and the driver now makes one. The TLS check only ever ran through a terminating test proxy, which never asks. It now also has a leg against a real TCPS listener.
- **10g and 11g: a LOB write's data** goes in the chunk form those servers read, by the LOB data's own rule (#427).
- **8i: reading a LOB walked its content once a packet**, O(n²) in its size (#400).

### Internals

- **The wire layer is on schemas** (#395, #398, #400). Every TTC message is now described by a declarative schema, encoded and decoded by one engine: login, describe, execute, fetch, LOBs, objects, AQ, two-phase commit, pipelining. The 10g+, 9i and 8i paths share them, where each used to have its own copy. Wire bytes are unchanged, as the replay corpus below checks.
- **Package-level PL/SQL types before 12.1 are a server limit, not a driver gap** (#193). seerdb measured that no client can describe or bind them there. The checks skip with that reason, and the README and the ROADMAP say so.

### Tooling

- **The replay corpus** (#396): a test-only build (`-Dwire_corpus=true`, never shipped) records every byte a live run exchanges, and replays it offline. Both live suites now run on all eight tiers with no database, in CI under ASan + UBSan: 29 replays. That includes the 8i, 9i, 10g, 18c and 26ai paths that no public container image covers. A recording leaves out DBA logins and the TLS legs (#425).
- **Matrix:** per-tier DBA logins, `SEER_<TIER>_DBA_USER` / `_PASS` (#409). The TLS proxy leg starts at 9i, and a real-TCPS leg runs on one tier (`SEER_TCPS_*`, #405).
- **More checks run on old servers.** Five 8i ODBC checks, and 9i's zero-fraction TIMESTAMP check, now use SQL those releases take, instead of skipping (#408, #420).
- **CodeQL:** loop-variable, float-equality, long-switch, empty-block and documentation findings are fixed.
- **Homebrew:** the formula points at the 0.5.0 tarball.

### Validation status (honest)

- **Live, full matrix green** (`tests/odbc/run-matrix.sh`, lab servers, master `36231b1` with this release's version bump). Pass / fail / skip:

  | | 8i | 9i | 10g | 11g | 18c | 21c | 23ai | 26ai |
  |---|---|---|---|---|---|---|---|---|
  | ODBC | 141/0/26 | 151/0/16 | 153/0/14 | 153/0/14 | 158/0/9 | 159/0/8 | 165/0/2 | 165/0/2 |
  | core API | 99/0/18 | 99/0/18 | 101/0/16 | 102/0/15 | 107/0/10 | 113/0/7 | 124/0/2 | 122/0/4 |

  The servers are 8i 8.1.7, 9i 9.2.0.4, 10g 10.2.0.5, 11g XE 11.2.0.2, 18c XE, 21c XE 21.3, 23ai Free, and 26ai (23.26.2) with native network encryption required. Each skip is a gap a release lacks, named with its reason in the suite.
- **TCPS against a real listener:** the lab's 23ai TCPS bed.
- **Windows, live, under Microsoft's ODBC Driver Manager**, on one Windows 11 (26H2) x64 VM. It used this release's own artifacts from a `release.yml` dry run, against all eight servers above:
  - the x64 and the x86 zip each pass `selftest.ps1` **27/0**, by connection string and by DSN;
  - the installer installs silently, both installed drivers pass `selftest -Installed` **25/0**, and it uninstalls leaving no driver registration or folder.
- **Offline:** 28 unit tests, in a plain and in an ASan + UBSan build. The replay corpus passes 29/0 in both.
- **GitHub CI (public tier):** 11g XE, 21c XE and 23ai Free containers, and the replay corpus, under ASan + UBSan. Also native and cross Windows builds, and macOS.
- **Not validated:** 12.1, 12.2 and 19c against real servers (12.1's wire level is exercised by capping a 21c session); Windows 10, Windows on ARM, and applications other than the test tools; the installer on 32-bit Windows. The TLS proxy leg doesn't run on 8i, whose listener redirects around the proxy (#412).
- **Known limitations:**
  - **Parameter arrays:** a query with one is refused, not run once per set (#431).
  - **11g binary XML:** values can't be decoded. No clean-room source for the CSX form exists (#434).
  - **8i national-character parameters:** a statement whose national-type parameters go to both VARCHAR2 and NVARCHAR2 targets still fails with ORA-12704, as does a `SQL_VARCHAR` parameter into an NVARCHAR2 column.
  - **Proxy authentication** is supported from 10g only.
  - **PL/SQL associative arrays on 9i** are waiting on a reference client (#254).
  - **Time zones** have the limitations listed for 0.5.0: region zones and LOCAL TIME ZONE, LOCAL TIME ZONE attributes in objects, and a session zone changed out of the driver's sight.
  - **DRCP on 11g** is not supported.
  - **Windows:** the installer is **not code-signed**, so SmartScreen may warn before it runs.

### Installing

- **Windows:** run `seerodbc-0.6.0-windows-setup.exe`, or unpack the zip for your application's bitness and run `register.cmd` from an elevated prompt. See `packaging/windows/README.md`.
- **Linux, from source:** `meson setup build && meson compile -C build`, then register `build/src/odbc/libseerodbc.so` (see `packaging/odbcinst.ini.sample`).
- **Fedora:** `packaging/seerodbc.spec` builds from this tag's tarball.
- **macOS:** as Linux, with Homebrew's OpenSSL 3 and unixODBC. The Homebrew formula moves to 0.6.0 once the tag exists, since it pins the tag's tarball.
